# Ragnarok's Edge Roadmap

## Core Identity

Ragnarok's Edge is an endless Norse myth dungeon runner first.

Everything else should deepen that loop, not replace it:

- choose a class
- gear up in Ravenwatch
- descend into a route
- survive deeper floors
- return with loot, relics, and progression
- rebuild and push farther next run

## The Four Layers

### 1. Moment-To-Moment

- movement
- attacks
- skills
- dodging
- positioning
- loot pickup

### 2. Run-Level

- how far can this run go?
- what bosses and modifiers appear?
- what loot and relics can be extracted?

### 3. Milestone-Level

- key floor intervals matter
- floor 25, 50, 75, 100 can carry stronger events, elites, bosses, or relic pressure
- floor 100 is the first major shard threshold

### 4. Meta-Level

- class growth
- subclass unlocks
- skill tree
- Ravenwatch upgrades
- Bifrost stabilization
- later era content

## Phase Roadmap

### Phase 1. Current Foundation

Goal:

- establish the endless descent loop
- make Ravenwatch feel like a stable hub
- let the player learn routes, scaling, loot, and class identity

Current shape:

- 3 dungeon routes
- endless floor scaling
- class identity
- gear and stash
- floor 100 shard rewards

This is the proof-of-fun phase.

### Phase 2. First Shard Cycle

Goal:

- complete the first major progression arc without abandoning the endless format

Player objective:

- recover 1 Bifrost shard from floor 100 of Barrow
- recover 1 Bifrost shard from floor 100 of Ember
- recover 1 Bifrost shard from floor 100 of Seer

Result:

- Ravenwatch stabilizes the first fracture
- the Broken Bifrost Gate becomes more than a dead relic
- the game prepares the player for the next layer

Design rule:

- this is the big mastery test
- later eras should not repeat the exact same 3x100-floor structure with only bigger numbers

### Phase 3. Subclass Era

Goal:

- expand buildcraft without replacing the core descent loop

New systems:

- subclass unlock through a quest in the next era
- subclass attunement in Ravenwatch
- 2 main-class skills + 2 subclass skills
- class-locked skill tree branches

Design rule:

- subclassing should feel earned
- the unlock should come from story progress, not a free menu choice

Suggested flow:

- the next era introduces a questline tied to the repaired gate
- completing it adds `unlockedSubclasses`
- players can attune one unlocked subclass at a time in Ravenwatch

### Phase 4. Salvage Economy

Goal:

- prevent stash bloat from endless loot accumulation

Problem:

- if every era only adds more loot, stashes become cluttered and progression gets muddy

Solution:

- every item should eventually resolve to one of three states:
  - equip
  - stash
  - salvage

Salvage outputs can become:

- forge currency
- rune dust
- relic fragments
- era crafting materials
- subclass attunement materials

Design rule:

- older loot should remain valuable as material, not only as permanent storage

### Phase 5. Next Era Expansion

Goal:

- expand the endless descent instead of replacing it with a new game

Each era should add:

- new route variants or route mutations
- new enemy families
- new bosses
- new loot families
- new environmental rules
- new progression quests

Design rule:

- later eras should change the baseline and add mechanics, not just reset numbers to zero

## Scaling Model

Use 3 overlapping scaling layers:

### Within-Run Scaling

- deeper floors increase danger
- stronger elites
- harder affixes
- denser rooms
- better loot

### Route Identity Scaling

- Barrow, Ember, and Seer should remain mechanically distinct
- later routes should add new behavior patterns, not only larger stats

### Era Baseline Scaling

- later eras start harsher than the original world
- the player does not "reset" into a beginner game again
- deep floors remain the true endless mastery test

## What Should Not Happen

Avoid these traps:

- every era requiring the exact same shard grind structure
- replacing the endless runner with a linear campaign
- letting stash growth outpace item usefulness
- adding systems that distract from the core descent loop

## Long-Term World Structure

### Ravenwatch

Ravenwatch is the anchor, not the whole world.

It begins as:

- the last safe place
- the stable wound-stitch
- the gateward hub

Later it becomes:

- the attunement point for subclasses
- the repair site for Bifrost progression
- the launch point into fractured ages

### The Bifrost

The Broken Bifrost does not need to end the game when repaired.

Instead:

- the first repair stabilizes local fractures
- later repairs open access to deeper ages and harder content
- the bridge expands the endless loop instead of concluding it

## Guiding Rule

If a feature is unclear, test it against this sentence:

> Every new system must deepen the endless descent loop, not distract from it.
